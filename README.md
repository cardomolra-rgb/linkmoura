# Moura Soluções Elétricas · Links

Página de links (estilo "link na bio") da **Moura Soluções Elétricas** — *Do projeto à ligação.*

Arquivo único: `index.html` (HTML + CSS, sem dependências além da fonte Montserrat do Google Fonts).

## Publicar no GitHub Pages

1. No repositório, abra **Settings → Pages**.
2. Em **Source**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Salve. A página fica em `https://cardomolra-rgb.github.io/linkmoura/`.

## Ativar os botões "Em breve"

No `index.html`, troque `class="btn soon"` por `class="btn light"`, coloque o link em `href` e apague o `<span class="tag">`.
